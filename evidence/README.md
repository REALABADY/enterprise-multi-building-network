# Project Evidence

This directory is reserved for screenshots and validation evidence captured from the final Cisco Packet Tracer configuration.

## Recommended Evidence Set

| # | File | Purpose |
|---:|---|---|
| 01 | 01-topology.png | Final two-building topology |
| 02 | 02-hsrp.png | HSRP Active/Standby verification |
| 03 | 03-etherchannel-b1.png | Building 1 EtherChannel verification |
| 04 | 04-etherchannel-b2.png | Building 2 EtherChannel verification |
| 05 | 05-stp-primary.png | STP Root Primary verification |
| 06 | 06-stp-secondary.png | STP Root Secondary verification |
| 07 | 07-ospf-neighbors.png | OSPF neighbor adjacency |
| 08 | 08-routing.png | Routing table verification |
| 09 | 09-dhcp.png | DHCP client addressing |
| 10 | 10-acl.png | ACL configuration/validation |
| 11 | 11-asa.png | ASA interfaces, routes, or OSPF evidence |

## Evidence Rules

- Add only screenshots that represent the final configuration.
- Keep device names and command output visible where practical.
- Use descriptive filenames.
- Avoid screenshots containing unrelated personal information.
- If a test was not completed, do not present it as completed evidence.

## Validation Priority

The most useful evidence for a network-engineering portfolio is:

1. Final topology.
2. HSRP redundancy.
3. EtherChannel.
4. STP.
5. OSPF adjacency.
6. Routing table.
7. DHCP.
8. ACLs.
9. ASA edge.
